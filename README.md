# Tare

**Find out if Kubernetes is worth it.**

A read-only CLI that shows you the evidence: real usage, real feature adoption,
on your Kubernetes cluster. No guessing.

A tare weight is what you subtract from a gross measurement to find the true
weight of the contents. Every Kubernetes cluster carries packaging — assumed
need, sunk cost, YAML nobody remembers writing. Tare subtracts that and weighs
what is actually there.

## Status

Early development. Not yet usable.
